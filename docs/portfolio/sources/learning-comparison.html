추가 1,000·8,000 step은 동일한 10,000-step checkpoint에서 각각 시작한 warm-start이다. optimizer, scheduler, RNG, sample stream과 step을 초기화한다. batch와 학습 스케줄 진행 조건이 함께 달라지므로 추가 업데이트 수나 batch 하나의 인과 효과로 해석하지 않는다.
