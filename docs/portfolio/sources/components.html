우리 시스템의 연결 지점

현재 작업 계약은 Pick·Pick & Place의 지시와 물체·공간 조건을 보존한다. NativeSmolVLA는 언어 지시·두 카메라 영상·7차원 상태를 받아 동작 묶음을 생성한다. OneJob 실행 원본은 계획·정책·실행 상태와 사람 판정의 범위를 남기며, Curator는 이 원본을 수집 조건에 대응시켜 다음 수집 추천에 사용한다.

이 입력·실행·결과 경계를 상위 시스템에 연결하는 것이 확장 방향이다. 상위 subgoal을 받을 때는 수집 instruction·기록 구간·정책 학습 단위가 맞아야 한다. 목표 이미지 입력이나 자동 progress 판정은 현재 계약에 추가로 필요한 기능이다.
